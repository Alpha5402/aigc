【第 0 轮 Prompt：视觉方向探索 + 整体结构设计策略】

你现在是“云上农管家 / AgriCloudManager”的移动端 UI/UX 视觉设计师与产品设计师。请在正式修改业务页面之前，先使用  $Web Design Engineer 等设计辅助能力，为本项目完成一轮高质量视觉方向探索和整体结构设计策略规划。

本轮不要急着大规模改业务页面。本轮目标是确定一套让人眼前一亮（强调眼前一亮）、适合竞赛展示、接近真实商业 App 的智慧农业移动端视觉方向，并明确后续页面如何在不破坏原有功能的前提下进行结构重设计。

项目背景：

* 项目名称：云上农管家 / AgriCloudManager。
* 项目类型：智慧农业服务 App。
* 技术栈：uni-app + Vue3 + SCSS。
* 主要端：App 端和小程序端优先，H5 端辅助。
* 用户群体：农户、合作社、农产品经营者，也需要适合竞赛展示。
* 核心功能：我的地、作物管理、添加作物、AI 农技问诊、农产品行情、销路匹配、感兴趣商户、营销助手、通知中心、运营轻后台。

一、设计目标

请不要只做“换颜色、加圆角、加卡片”的普通美化。最终效果要有真实 App 产品感，有视觉记忆点，让人第一眼觉得专业、美观、有完成度。

整体目标：

* 美观、自然、可信、专业。
* 符合农业、农田、作物、生长、丰收、农产品销售、智慧农服等主题。
* 有现代移动端 App 质感。
* 适合比赛展示。
* 可以在农业主题范围内更炫酷一些，但不能乱。
* 长时间使用舒适，不刺眼、不廉价、不土味。
* App 端优先，H5 端正常兼容。

二、允许重设计整体结构

本次前端优化不是简单换皮。允许你在不破坏原有功能模块和业务能力的前提下，对页面整体结构、信息层级、组件组织和交互方式进行重新设计。

允许调整：

1. 页面信息架构。
2. 页面模块顺序。
3. 卡片布局。
4. 顶部视觉区。
5. 底部操作区。
6. 表单分组方式。
7. 列表改卡片。
8. 普通按钮改成底部操作栏。
9. 普通弹窗改成底部抽屉。
10. 普通列表页改成更有 App 质感的首页、看板或工具页。
11. 页面视觉重点和交互路径。
12. 功能入口的呈现方式。
13. 图标、图片、canvas、视觉装饰的使用方式。

示例方向：

* “我的地”不必保留普通列表结构，可以重构成首页级农场管理看板。
* “行情页”不必保留表格或简单列表，可以改成农业价格数据看板 + 行情卡片 + 趋势图。
* “销路匹配”不必保留普通商户列表，可以改成供需匹配页、推荐卡片、地图感区域、匹配理由展示。
* “营销助手”不必做成普通表单 + 文本结果，可以改成输入配置区、风格选择区、生成结果卡片和复制操作区。
* “AI 问诊”不必做成聊天机器人页面，可以改成农技问诊工具流：症状描述、图片上传、分析中反馈、结果建议卡片。
* “通知中心”不必只是消息列表，可以改成分类消息中心。
* “登录 / 注册”可以重构为更有品牌感的欢迎页 + 表单卡片。

三、必须保留的功能边界

虽然允许重构页面结构，但不能改变或删除项目原本应该具备的功能模块。

必须保留：

1. 登录 / 注册能力。
2. 我的地 / 作物管理能力。
3. 添加作物能力。
4. 编辑 / 删除 / 查看作物相关能力，如果原项目已有。
5. AI 智能问诊能力。
6. 图片上传能力，如果原项目已有。
7. 行情查看能力。
8. 销路匹配能力。
9. 感兴趣商户能力。
10. 营销文案生成能力。
11. 通知中心能力。
12. 运营轻后台能力。
13. 管理员权限判断和管理端接口逻辑。
14. 原有前后端接口字段和调用逻辑。
15. 原有路由关系和页面跳转能力。

可以改变“怎么展示、怎么组织、怎么交互”，但不能改变“这个功能是否存在、能否正常使用”。

四、最重要的视觉底线

严禁以下风格：

1. AI 模板风。
2. 大面积蓝紫渐变。
3. 霓虹发光边框。
4. 赛博网格背景。
5. 大量玻璃拟态。
6. 抽象 AI 大脑、机器人、芯片、宇宙科技背景。
7. ChatGPT 式通用聊天界面套壳。
8. 通用 SaaS 后台风。
9. 传统政府后台风。
10. 土味农业网站风。
11. 廉价农产品促销页风。
12. 金融行情 App 风。
13. 外卖 / 电商大促风。
14. 游戏化种田风。
15. 与智慧农业主题无关的泛科技风。

AI 功能应该通过“流程清晰、结果可信、反馈自然、农技辅助感强”来体现，不要靠蓝紫渐变、机器人和发光效果来体现。

五、允许使用公开资源提升质感

为了实现“眼前一亮”的效果，可以主动寻找并使用网上公开的高质量图片、图标、插画和视觉资源，但必须保证许可清晰。

允许使用：

* 高质量真实农田照片。
* 温室大棚图片。
* 果园、菜地、作物特写。
* 农产品市场、丰收场景。
* 农业科技设备。
* 农户田间管理场景。
* 开源图标。
* 开源插画。
* 地图、天气、数据类视觉元素。
* 轻量自然纹理，例如田垄线条、叶片纹理、浅色地形纹理。

素材要求：

1. 不要生成图片。
2. 不要使用版权不明素材。
3. 不要使用带明显品牌识别的素材。
4. 不要使用其他 App 截图。
5. 不要直接热链远程图片。
6. 必须下载到本地 static / assets 目录。
7. 图片需要压缩，适合移动端加载。
8. 必须维护 ASSET_CREDITS.md，记录素材文件名、来源平台、原始链接、license、用途、是否压缩或裁剪。
9. 使用任何“免费素材”前都要确认当前 license，不要默认所有公开资源都可随便用。
10. 素材风格必须统一，不要一页真实照片、一页 3D 插画、一页卡通图标混用。

推荐素材气质：

* 明亮。
* 干净。
* 自然。
* 真实。
* 有生命力。
* 有轻微科技感。
* 适合农业生产和农产品销售场景。
* 适合移动端裁切。

避免素材气质：

* 过度卡通。
* 低清晰度。
* 强 AI 生成感。
* 赛博蓝紫科技感。
* 土味宣传海报感。
* 廉价电商促销图。
* 风格混乱的 3D 图标。
* 与农业无关的抽象科技图。

六、允许合理使用 canvas

允许使用 canvas 来提升视觉完成度，但 canvas 只能作为局部视觉增强，不能替代正常页面布局、组件和业务交互。

允许 canvas 用于：

1. 我的地页面：轻量农田纹理、地块线条、作物生长感背景、天气、光照、水滴、叶片等自然装饰。
2. 行情页：小型价格趋势图、行情卡片 sparkline、数据看板微型图表。
3. 销路匹配页：匹配度环形图、供需连接示意、地区 / 距离 / 匹配路径的抽象地图感背景。
4. AI 问诊页：轻量分析进度动画、图片识别 / 症状分析的柔和反馈。
5. 营销助手页：丰收感装饰、果实、麦穗、商品标签等轻量装饰、生成中状态小动画。

canvas 禁止用于：

* 蓝紫霓虹粒子。
* 赛博网格。
* 抽象 AI 大脑。
* 机器人视觉。
* 芯片电路风。
* 强发光光球。
* 与农业无关的炫酷动效。

canvas 技术要求：

1. 不能把整个页面做成 canvas。
2. 页面主体必须仍然使用 uni-app / Vue 组件实现。
3. canvas 只能用于局部背景、图表、装饰、趋势线、进度图。
4. 必须兼容 App 端和 H5 端。
5. 避免直接依赖浏览器专属 API。
6. 平台差异代码要做好条件编译和降级处理。
7. 必须控制性能，页面离开时停止动画。
8. 静态效果优先绘制一次，不要持续重绘。
9. canvas 初始化失败时，页面仍然能正常显示。
10. canvas 背景层不能遮挡点击、滚动、输入、上传、路由跳转和底部导航。
11. 多页面使用时请封装组件，例如 FarmPatternCanvas、TrendMiniChart、MatchProgressCanvas、AiAnalysisCanvas、HarvestDecorCanvas。
