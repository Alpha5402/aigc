# 单页返工通用规则

只重构当前指定页面，不做全页面批量优化。不用做检查，交给我进行视觉检查就行。某些操作被拒绝了就不用尝试了（权限申请的除外）。

继承“我的地”样板页视觉语言：
- 眼前一亮的设计感
- 米白 + 叶绿主色
- 真实农业素材氛围
- 圆角经营卡片
- 清爽自然
- 有 App 产品感

要求：
1. 先重构信息架构，再做样式。
2. 不要只在原页面基础上加图片、圆角和阴影。
3. 每个页面根据业务场景单独设计，不要复用同一张素材造成模板感。
4. 可使用公开图片、开源 icon、SVG、线稿、纹理、canvas，但必须服务页面业务。
5. 禁止使用 emoji。
6. 禁止 AI 蓝紫、赛博、机器人、芯片、电路、AI 大脑、宇宙科技背景。
7. 不改接口、路由、后端、权限逻辑和核心业务逻辑。
8. 完成后不用输出。
